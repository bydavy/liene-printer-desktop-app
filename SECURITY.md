# Security

This project talks to a local Bluetooth printer. It does not run a network
service and does not upload photos or printer data anywhere.

To report a security issue, use GitHub's private vulnerability reporting for
the repository (Security → Advisories) if available, or open an issue that does
not include sensitive details (MAC addresses, serial numbers, account data, or
personal file paths).

The bundled releases are ad-hoc signed and not notarized. Verify the SHA-256
published with each release before running a downloaded DMG.
